# Student Performance Analysis

## About the Project
A Python project that analyzes student grades using Pandas and visualizes results using Matplotlib.

## Features
- Read student data from a CSV file.
- Calculate each student's average score.
- Identify the highest and lowest student averages.
- Compare average scores across subjects.
- Generate bar charts.
- Create a summary report in a text file.

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Project Files
- main.py: Main Python program.
- students.csv: Student grades dataset.
- report.txt: Generated summary report.
- student_averages.png: Student averages chart.
- subject_averages.png: Subject comparison chart.

## How to Run
1. Install the required libraries:
   pip install pandas matplotlib

2. Run the program:
   python main.py
